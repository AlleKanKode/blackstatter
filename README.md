# Blackstatter
Er en app bygget til at holde øje med prisniveauer på produkter i danske webshops.

Den er skrevet i Python ved hjælp af Googles Antigravity software.
Den bliver produceret på Alle Kan Kodes adventslivestreams som sendes hver søndag i Advent live på youtube.

Kig med på Alle Kan kodes Youtube kanal : https://www.youtube.com/@AlleKanKode

Og hop ind på https://allekankode.dk for at melde dig på mail listen.
